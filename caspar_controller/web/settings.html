Devices send a key as an X-API-Key header or ?api_key=. Rotating a key breaks every device using the old one.

CasparCG Executable

Download CasparCG Server from github.com/CasparCG/server/releases and extract it, then point to the casparcg.exe inside.

⚠ CasparCG path is not set — the app cannot start CasparCG until this is configured.

Per-instance config files are written to the same folder as the exe when CasparCG is started.
