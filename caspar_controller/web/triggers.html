Build a trigger

How it works

The trigger is an HTTP GET to this controller, which plays the clip on that output at once. Every trigger needs this controller's API key (Settings → API Key): in the URL as api_key=, or in an X-API-Key header, which keeps it out of URLs and logs. Rotating the key in Settings stops every trigger until it's updated.
