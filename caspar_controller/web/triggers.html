Build a trigger

How it works

The trigger is an HTTP GET to this controller, which plays the clip on that output at once. Triggers use this controller's trigger key (Settings → API Keys), which can fire clips and nothing else: in the URL as api_key=, or in an X-API-Key header, which keeps it out of URLs and logs. Settings can also limit which addresses may use the keys. Rotating the trigger key stops every trigger until it's updated.
