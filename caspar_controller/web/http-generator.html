How it works

Send the generated URL as an HTTP GET request from any device on the same network. The app will forward the clip to the selected CasparCG instance immediately.

Works from a web browser, curl, a Companion button, a touchscreen panel, or any automation system that supports HTTP requests.

Every request needs this controller's API key (Settings → API Key). The URL above includes it as api_key=. Where a device can send headers, prefer X-API-Key so the key stays out of URLs and logs:

curl -H "X-API-Key: <key>" "/api/load?instance=Clipplayer&clip=MYCLIP"
