Set up Caspar Controller

Five steps to live NDI outputs. Settings has everything else, and you can come back here any time.

Where is CasparCG?

The path to casparcg.exe. Don't have it? Download CasparCG Server from github.com/CasparCG/server/releases and extract it.

Checking for NDI…

Install the NDI Runtime from ndi.video/tools, then restart Caspar Controller.

Your outputs

Each output is one CasparCG with its own NDI source. HTML outputs show a web page (graphics); media outputs play clips.

Keys for Automator, Companion and panels

Devices that fire clips need a key. Give Automator and panels the trigger key, which can only play clips. The full key is for Companion setups that start and stop outputs, and for other controllers.

The Triggers page builds ready-to-use URLs with the key in.

Start the outputs

They start one at a time, 5 s apart, so receivers lock onto the right NDI source. Watch them come up on the Dashboard.

Set a password

Until a password is set, only a browser on this PC can use Caspar Controller. Once it's set, this browser signs in like any other.
